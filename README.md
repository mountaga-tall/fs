# F&S USA Bazar Corner

Site vitrine e-commerce statique, mobile-first, pour F&S USA Bazar Corner à Abidjan.

## Pages
- Accueil
- Boutique
- Arrivages
- À propos
- Contact

## Fonctionnalités
- Navigation responsive avec menu mobile
- Recherche et filtres de boutique
- Messages WhatsApp contextualisés pour les demandes produits
- Partage natif / copie de lien
- Animations au scroll et micro-interactions
- SEO on-page + canonical + Open Graph + données structurées
- Sitemap et robots.txt
- PWA installable avec manifest et Service Worker
- Cache offline des pages et assets déjà visités
- CNAME configuré pour `juzabazar.ci`

## Déploiement
Le projet ne nécessite pas de build. Publier le contenu du dossier `fs-main/` sur GitHub Pages, Cloudflare Pages ou un hébergement statique équivalent.

Le fichier `CNAME` définit le domaine personnalisé : `juzabazar.ci`.
